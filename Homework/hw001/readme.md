#### BMI 계산법 
> BMI = 몸무게(kg) / 키(m)^2

---

#### BMI 판별법
```
저체중 : 18.5 미만
정상 : 18.5~22.9
비만 전단계(과체중) : 23~24.9
1단계 비만 : 25~29.9
2단계 비만 : 30~34.9
3단계 비만(고도비만) : 35 이상
```

### 계획

1. heal.txt에 정보입력
1. heal.txt의 정보를 bmi.py에서 계산
1. bmi.py에서 터틀 그래픽으로 보여주는 코드 작성
